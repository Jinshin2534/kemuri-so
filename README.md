# けむり相（kemuri-so）

顔を撮ると、吸っていそうなタバコの銘柄を確率で返します。
そして「それは本当に当たっているのか」をクイズで確かめられます。

## 遊び方

1. 顔を撮る → 上位3銘柄と、その判定に何が効いたかが出る
2. その場で「実際は何を吸っていますか？」に答える → 学習データになる
3. データが増えるほど、判定が統計ではなく手元のデータを見るようになる
4. クイズで、あなた・AI・でたらめ の正解率を並べる

## 正直なところ

顔と銘柄を対応づけた公開データセットは存在しません。
だからこのアプリの判定は、まず**年代・性別ごとの統計**で当たりをつけ、
登録データが集まった分だけ**顔ベクトルのkNN**で補正する、という作りになっています。

```
P(銘柄) ∝ P(銘柄 | 年代, 性別) × L(顔ベクトル | 銘柄)^w      w = n / (n + 20)
```

判定結果には毎回「統計 79% ／ 手元のデータ 21%」のように**何が効いたか**を出します。
登録が少ないうちは、ほとんど年代と性別だけで言っています。
4択クイズの「でたらめ 25%」の線を超えられるかどうかが、この試みの答えです。

## データの扱い

- 顔写真も顔ベクトルも**この端末の中（IndexedDB）だけ**に保存されます。サーバはありません
- 書き出しは既定で**写真を含めません**。数値の列と銘柄だけになり、顔には戻せません
- 種データ `public/seed.json` は、自分で登録したものを「写真を含めずに書き出す」で作れます
- 喫煙は20歳から。未成年の顔を登録しないでください。自分以外を登録するときは本人の同意を得てください
- 顔から銘柄が分かるという科学的根拠はありません

## 統計の出典

- 厚生労働省「令和5年 国民健康・栄養調査」 https://www.mhlw.go.jp/content/10900000/001338334.pdf
- リラゾ「加熱式たばこ人気シェア率調査」2026年1月, n=4,529 https://relazo.net/tabacco-share/

紙巻きたばこの「銘柄 × 年代」のクロス集計は公開されていないため、そこは推定値です。
アプリ内の「データ」画面に、推定値がいくつあるかを表示しています。

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:5410
pnpm test    # src/lib の純粋関数
pnpm build
```

- `src/lib/` … DOM も face-api も知らない純粋関数。ここだけがテスト対象
- `src/face/` … face-api の薄いラッパ。差し替えられるので、テストはカメラ無しで通る
- `src/db/` … IndexedDB
- `src/ui/` … 画面

カメラの無い環境では、コンソールから次が使えます。

```js
await window.__app.reset();
await window.__app.mockRegister('wakaba', 1, { withPhoto: true });
const r = await window.__app.mockJudge(1);   // 顔を作って判定まで
await window.__app.feedFace(face);           // 顔ベクトルを直接与えて判定だけ
await window.__app.records();
```

## 実装メモ

- **平滑化定数は固定値にしてはいけない。** 他人同士の顔ベクトルは距離が1前後になり、
  カーネルの出力が 0.02 程度にしかならない。固定 α を26銘柄ぶん足すと手元のデータの声が完全に飲まれ、
  60件登録しても事後分布が動かなくなる。`α·√(1 + Σscore)` と証拠量でスケールさせている
- face-api のライブラリ本体（1.3MB）とモデル（7.1MB）は、**判定・登録の画面を開いた時点で先読み**する。
  初回推論はシェーダのコンパイルが走って重いので、読み込みのうちに一度空打ちして済ませてある
- TF.js のバックエンドは `webgl` を明示指定する。放っておくと CPU に落ちることがあり、
  そのときは初回推論が **23秒** かかった（webgl なら読み込み＋ウォームアップ込みで 2.2秒）
- **ヘッドレスのブラウザでは顔検出の実測ができない。** このリポジトリを検証したペインは
  `document.hidden === true` が固定で requestAnimationFrame が発火せず、
  TF.js の WebGL フェンス待ちが進まないまま止まる。
  ロジックの確認は `window.__app.mockJudge` / `feedFace` で行い、
  実写での検出は実機のブラウザで確かめること
